# 🚀 Eshaan Kachru — Data Analyst Portfolio

A modern, responsive portfolio website showcasing my skills, projects, and credentials as an aspiring Data Analyst.

🔗 **Live Site:** [ekachru8.github.io/portfolio](https://ekachru8.github.io/portfolio/)

---

## ✨ Features

- **Dark / Light Mode** — Toggle between themes with automatic system preference detection
- **Interactive Skills Chart** — Filterable Chart.js visualization of technical proficiencies
- **Project Case Studies** — Glassmorphic modals with KPIs, execution details, and tech stacks
- **Animated Timeline** — Education & certifications displayed in a vertical scroll timeline
- **Particle Background** — Dynamic canvas-based particle animation in the hero section
- **Fully Responsive** — Optimized for desktop, tablet, and mobile with a slide-out drawer menu
- **Scroll Reveal Animations** — Smooth entrance animations powered by Intersection Observer
